## About the Project
A simple Python command-line application that lets students view lab
equipment, enter a quantity and date, and submit a booking request.
The system accepts or rejects the request based on the rules.
The main goal is to apply Software Quality Engineering (SQE) techniques
to test the system and measure its quality.
